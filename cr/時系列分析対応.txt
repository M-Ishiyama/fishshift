# Change Request: 過去データに基づく翌日出航時の海流・風向推定とガソリン（燃料）試算の追加

`DESIGN.md` の仕様・制約（実データ検証の徹底、過去観測と予報の明確な区別、試算条件・仮定係数の明示、実航海への使用禁止免責、pytestによる数理テスト）を厳守したうえで、**Route Lab（S-04）に「翌日出航予定（未来日時）の海流・風向推定およびガソリン等燃料試算機能」**を追加してください。

---

## 1. 変更目的と設計方針
- ユーザーが翌日の出航予定時間帯を選択し、**過去の海流・風データ（NASA PO.DAAC CCMP風・海流履歴等の同季統計値）**または**翌日予報（Open-Meteo Marine/Weather API）**を切り替えて、目的地までのガソリン（または軽油・A重油）消費量・燃料費を事前試算できるようにする。
- **科学的誠実さの原則（厳守）**：
  - 過去データに基づく統計推定は「平年・同季の気候値ベース」であり、**翌日の突発的な低気圧・前線通過・荒天は予測できない**ことをUI上で明確に注記すること。
  - 「過去統計ベース」と「翌日予報モデル」を絶対に混同せず、参照した算出根拠・対象日時を常に画面表示すること。

## 2. 型定義とデータ準備（`src/schemas.py`, `src/repository/snapshot.py`）
1. `RouteEstimate`（`src/schemas.py`）および船舶パラメータ型に以下を追加・拡張する：
   - `condition_basis: Literal["historical_climatology", "next_day_forecast"]`
   - `departure_datetime: str`（例: 翌日 `04:00` / `09:00` / `15:00`）
   - `fuel_type: Literal["gasoline", "diesel"]`
   - `avg_wind_assist_knots: float`（針路方向に対する追い風/向かい風成分）
   - `assumptions` リストに「使用した風圧抵抗感度・波浪抵抗感度・算出根拠」を必ず格納する。
2. **過去統計ベースグリッドの構築（`src/repository/snapshot.py` / `scripts/`）**
   - 対象海域・対象月（出航予定月に一致する過去複数年のデータ）から、海流 `(u, v)` および海上風 `(u10, v10)` の気候学的平均（または中央値）を抽出し、スナップショットとして利用可能にする。
   - 出航時間帯（`04:00` / `09:00` / `15:00`）による日変化補正を入れる場合は、**それが「仮定した時間帯補正係数」であることを `assumptions` に明記**し、観測事実と混同しないこと。

## 3. 燃料・速度試算ロジックの拡張（`src/processing/routes.py`）
`estimate_route_fuel(...)` に、従来の「海流アシスト」と「波浪抵抗」に加えて **風向・風速による空力抵抗（追い風／向かい風）** を組み込む：
1. **風向の向き変換（必須）**
   - 気象の風向は「吹いて**くる**方向（FROM）」であるため、必ず吹いて**いく**方向 `wind_to_deg = (wind_from_deg + 180) % 360` に変換したうえで、船の進行方位 `vessel_heading_deg` との余弦 `cos(wind_to_deg - vessel_heading_deg)` を取ること。
2. **風速の単位統一**
   - `1 m/s = 1.94384 knots`、`1 knot = 1.852 km/h` で統一換算すること（API単位が `km/h` の場合は先に `m/s` 等へ正規化）。
3. **実効対地速度・燃料計算モデル**
   - `effective_speed_knots = max(min_speed, base_speed_knots + current_assist_knots + wind_assist_knots - wave_penalty_knots)`
   - ここで `wind_assist_knots = wind_speed_knots * coupling_coeff * cos(angle) * wind_drag_factor` とし、係数（例：`coupling_coeff = 0.045`）は未校正の仮定値として `src/config.py` に定数定義し、UIに表示すること。
   - 向かい風区間（`wind_assist_knots < 0`）では速度低下に加え、仮定の風圧燃料ペナルティ係数を適用する（`wind_drag_factor = 0` にすると風影響ゼロになること）。
   - 削減率・差分が出ない場合はそのまま `0%` や増加分を表示し、恣意的な演出をしない。

## 4. UI / UX 要件（`src/ui/pages/route_lab.py` & `about.py`）
1. **翌日出航設定パネル**
   - 出航予定日：翌日（`today + 1 day`）および時間帯スロット（`04:00 朝便` / `09:00 午前便` / `15:00 夕方便`）を選択可能にする。
   - 算出根拠切替：`過去統計ベース（NASA等履歴）` と `翌日予報（Open-Meteo）` を切り替え可能にし、予報キャッシュが無い場合は自動で過去統計ベースへフォールバック＋通知表示する。
2. **燃料種別とパラメータ入力**
   - 燃料種別セレクター：`ガソリン（小型船想定）` / `軽油・A重油`（切替時に標準的な燃料単価・消費率の初期値をセットし、ユーザーがスライダーで自由調整可能にする）。
   - 既存の `船速 (knots)`・`基本燃費 (L/h)`・`燃料単価 (円/L)`・`波浪抵抗感度` に加え、`風圧抵抗感度` スライダーを追加する。
3. **比較出力と安全免責**
   - Route A（最短距離ライン）と Route B（海況・海流配慮ライン）の比較表に **`平均風向アシスト (kt)`** と **`推定燃料消費量 (片道 L)` / `推定燃料費 (片道・往復参考 円)`** を追加する。
   - `Experimental estimation — not for navigation`（試算であり実航海判断には使用不可）および「過去統計ベースは突発的な荒天を反映しない」旨の注意書きを常時表示する。

## 5. テスト要件（`tests/test_routes.py` に pytest 追加）
- `T-R11`（向かい風・追い風対称性）: 同一距離・無波浪・無海流条件において、船首に対し真後ろからの追い風より真正面からの向かい風の方が、実効速度が低下し推定燃料消費量が多くなること。
- `T-R12`（風向FROM→TO変換精度）: 船が真東（`90°`）へ航行し、西風（`wind_from_deg = 270°`）が吹いているとき、`wind_assist_knots > 0`（追い風アシスト）として計算されること。
- `T-R13`（感度・フォールバック）: `wind_drag_factor = 0.0` のとき風速が燃料計算に影響しないこと、燃料単価・種別変更が燃料費に線形反映されること、および予報データ欠損時に `historical_climatology` で正常に試算が継続できること。

## 6. 完了条件
- `Route Lab` 上で、翌日出航の時間帯・算出根拠（過去統計 vs 予報）・燃料種別（ガソリン / 軽油・A重油）を切り替えて比較試算が動作すること。
- 既存および新規追加の `pytest`（`T-R11` 〜 `T-R13` 含む）が全件パスすること。
- `About & Data` および `README.md` に、過去統計ベース推定の算出方法と科学的限界が明記されていること。
